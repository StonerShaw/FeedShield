# 小红书发现遮罩

这是一个安卓辅助 App。检测到小红书的「发现」界面后，它会用遮罩挡住推荐区域并拦截这块区域的触摸。顶部搜索和底部导航仍可点击。打开搜索、切到其他界面或离开小红书后，遮罩会撤掉。

## 安装和验证

1. 从 [Releases](../../releases/latest) 下载 APK，传到安卓手机并安装。支持 Android 8.0 及以上。
2. 打开「小红书发现遮罩」，进入无障碍设置，启用同名服务。
3. 打开小红书的「发现」，检查推荐区是否被挡住。在遮罩中央向上滑动，确认笔记不会跟着滚动。
4. 点顶部搜索，输入关键词，打开一条结果。回到「发现」时，遮罩应恢复。底栏「我」仍可进入收藏和赞过。

如果无障碍开关提示「受限设置」，可以在安卓设置的「应用」中打开本 App 的应用信息，查看右上角菜单有无「允许受限设置」。关闭该无障碍服务即可停用遮罩。

## 实现范围

- 遮罩拦截滑动和点击。小红书后台仍可能请求推荐数据。
- 页面识别基于无障碍节点的标签、位置和选中状态。无法识别「发现」时，遮罩不会显示。
- APK 不申请网络权限，也不存储读取到的界面内容。
- 已验证 APK 的构建和签名。小红书真机兼容性待测试。

## 从源码构建

用 Android Studio 打开本目录，使用 JDK 17、Gradle 8.11.1 和 Android SDK 35。同步后执行 Gradle 任务 `assembleDebug`。

## 0.2 调整

- 在设置页用「向上扩大」「向下扩大」修正露出的边缘。建议每次调 8 dp 后回到发现页检查。底部扩张限制在识别到的导航文字上方，顶部扩张会避开识别到的搜索控件。
- 「打开电池优化设置」提供系统入口。如果是遮罩服务切后台后掉线，先回到无障碍设置检查服务，再查看系统是否限制这个辅助 App 的后台运行。该辅助 App 不会主动结束小红书进程。

## 0.3 调整

收到顶部或底部导航区域的点击事件时先撤罩，再确认页面。普通内容变动合并处理，避免推荐流密集更新时反复扫描。

## 0.4 调整

遮罩默认跟随安卓系统的深色模式。若小红书单独设了主题，可在辅助 App 的「遮罩颜色」选「浅色」或「深色」。

## 0.5 调整

点击、选中状态和窗口变化会优先触发页面识别。防闪回等待只用于界面仍显示旧的「发现」节点时。一旦观察到离开，返回「发现」就按新页面状态立即恢复遮罩。

## 0.6 调整

打开「每天定时启用遮罩」并设置启用和停用时间。按手机本地时间每天重复，支持跨午夜。两个时间相同时表示全天启用。关闭定时后，遮罩恢复为全天可用。定时控制遮罩是否显示，无障碍服务由系统设置管理。
