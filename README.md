# FeedShield

FeedShield 0.10 是适用于 Android 8.0 及以上的推荐流遮罩。用安卓无障碍服务遮住特定页面里的推荐区域。例如可以保留搜索框和底部导航，把两者之间的推荐流挡住。支持多时段定时和浅色、深色遮罩。

## 自定义 App

1. 安装 APK，打开 FeedShield，启用同名无障碍服务。
2. 点「添加 App」并选择目标应用，切到要遮住的页面，在浮动按钮上点「检测此页」。
3. 确认建议范围，必要时上下拖动蓝色区域的边线。若能读到明确的选中标签，会直接进入试用；需要对照时，切到同一栏里的另一个标签，再点「确认相邻标签」。
4. 回到目标页试用，点搜索或切标签检查遮罩是否正确撤下。确认后点「保存规则」。试用中可点「调范围」继续编辑。试用不受全局定时影响。

每个 App 可保存一个自定义规则。点规则行可以调整边界和查看上次检测结果。录制只影响选中的 App，离开后可回来继续，十分钟未保存会结束。学习使用屏幕顶部和底部的无障碍标签及选中状态。如果区分不出两页，可换同一栏里的另一个标签，或取消录制。横竖屏和窗口比例差异较大时，规则会放行。改版后若页头变化，可重新录制。

## 小红书升级

沿用原安卓包名和签名，可以覆盖安装。已有定时、颜色和边界设置会保留。小红书「发现」预设默认开启，也能从规则详情进入可视化范围编辑。小红书有自定义页面规则时，以该规则为准。各 App 共用定时设置。

跟随系统配色时，Android 11 及以上会在浅色系统下尝试取样已遮罩页面的页头和底部颜色。检测到深色即使用深色遮罩。检测不可用时使用系统配色。取样图像只在内存中用于判断颜色，随后释放。

自定义规则只在本地保存包名、遮罩比例和用于匹配的标签散列。应用没有网络权限。遮罩挡住屏幕上的内容和触摸，原 App 仍可以在后台加载推荐。

## 下载与构建

从 [GitHub Releases](https://github.com/StonerShaw/FeedShield/releases/tag/v0.10) 下载 `FeedShield-0.10.apk`。从小红书专用版覆盖安装时可保留原设置。

用 Android Studio 打开本项目，使用 JDK 17、Gradle 8.11.1 和 Android SDK 35。同步后运行 `assembleDebug`。
